## 这一幕在算什么

一颗岩石行星从岩浆海冷却成蓝色星球。核心是**真实的大气散射**：瑞利散射（∝ 1/λ⁴）与米氏散射，
系数取地球大气的实测值，单次散射逐像素积分。天为什么是蓝的、晨昏线为什么是红的，都直接从这组数里长出来，不靠调色。

## 尺度（用真实值，单位 km）

- 行星半径 R = 6371；大气顶 R + 100。
- 瑞利：β_R = (5.802, 13.558, 33.1)×10⁻³ km⁻¹（对应 680 / 550 / 440 nm），标高 H_R = 8.0。
- 米氏：β_M = 3.996×10⁻³ km⁻¹（散射）、消光 ×1.11，标高 H_M = 1.2，相函数用 Cornette–Shanks 或 HG，g = 0.8。
- 臭氧吸收（可选，让晨昏线上方出现蓝紫过渡）：(0.650, 1.881, 0.085)×10⁻³ km⁻¹，帐篷形分布，中心 25 km、半宽 15 km。
- 大气是真实比例的薄：从轨道上看，蓝色只是行星边缘一道细线。这正好对上字幕「一层薄薄的蓝色」——不要为了好看把大气加厚。
- 着色器里的大数（6371 量级）注意精度：求交时先减去行星中心，判别式用稳定的写法。

## 实现

- **全屏逐像素**：光线 → 与行星 / 大气壳求交 → 地表着色 → 沿视线积分单次散射（观测者在大气外）。
- **透射率查找表**：`init` 时用一个全屏着色器预计算 `T(高度, 太阳天顶角余弦)` 到 256×64 的 `rgba16f` 目标，散射积分时查表，把内层光线步进省掉。视线方向 16–24 步，按密度做非均匀步长。
- **地形**：单位方向上的域扭曲 fbm，高程 −6 到 +5 km。用 `noised` 的解析梯度算法线（不要有限差分）。远处的高频要淡出，避免闪烁。
- **熔岩期**（0–30）：地表温度场 `T(x, t)` 由约 1600 K 冷却到约 600 K，裂纹（ridged 噪声）比板块冷却得慢；发光用 `blackbody(T)`，亮度按 T⁴ 标定后压到合适的曝光。0–14 秒里有若干次陨击（位置、时刻由 `ctx.rng` 在 `enter` 时确定）：一次白闪 → 扩张的发光环 → 留下逐渐变暗的坑。
- **蒸汽期**（14–30）：浓厚的灰白云层逐渐包裹行星，被恒星照亮，背面透出下方岩浆的暗红。云里偶有闪电。
- **降雨成海**（30–46）：`ctx.cue('rain')`。海平面从最低处逐渐上升到最终值；海岸线随之推进。云层变薄、散开。
- **天空转蓝**（46–60）：散射强度从"浑浊的早期大气"平滑过渡到上面那组真实系数。
- **第一抹绿**（60）：`ctx.cue('green')`。植被从海岸线向内陆蔓延（用"高出海平面的高度"与湿度噪声做阈值，阈值随时间推进），60–75 秒间完成。两极与高山有冰雪，内陆有荒漠。
- **海洋**：深海暗蓝，近岸浅水偏青；恒星的镜面反射用带法线噪声的 GGX，晨昏线附近的耀斑要好看。
- **云**：一层位于 8–12 km 的二维云，覆盖率来自噪声，随纬度带不同速度流动（用 `curl` 或分带旋转），被恒星照亮、给地面投一点影；晨昏线附近的云被染成橙红——这应当从散射计算里自然得到。
- **夜面**：68 秒之后，夜面沿海岸出现极其微弱、稀疏的暖色灯火。不要点题，不要多。
- 恒星光：`blackbody(5800)` × 强度，方向固定。背景用 `sky`，行星前方的星空被行星挡住。

## 解剖面板

- lead：「每个像素沿视线穿过大气，逐段计算有多少星光被空气分子散射进你的眼睛。天的蓝、晨昏的红，都来自同一组实测系数。」
- equations：
  - 瑞利散射：`β_R(λ) ∝ 1/λ⁴`
  - 单次散射：`L = ∫ T(观测者→p)·β(h)·P(θ)·T(p→恒星)·E_sun ds`
  - 透射率：`T = exp(−∫ β(h) ds)，  β(h) = β₀·e^(−h/H)`
  - 瑞利相函数：`P(θ) = (3/16π)·(1 + cos²θ)`
- notes：
  - 「蓝光（440 nm）被散射的本领是红光（680 nm）的 (680/440)⁴ ≈ 5.7 倍。」
  - 「日落时光要斜穿过几百公里的空气，蓝光在半路就被散射掉了，剩下的是红。」
  - 「大气的厚度不到行星半径的百分之二。这里按真实比例画。」
- live：地表平均温度（K，1600 → 288）；海洋覆盖率；大气透明度或天空亮度；距今（亿年）。

## 物理自检（检验真正在跑的那份着色器代码与查找表）

1. **1/λ⁴**：着色器所用系数的 β(440)/β(680) = 5.70 ± 1%。
2. **天顶光学厚度**：在探测程序里沿天顶数值积分瑞利光学厚度，与解析值 `β·H·(1 − e^(−100/H))` 相差 < 1%。
3. **查找表正确**：透射率表在 3 个采样点上与直接数值积分相差 < 1%。
4. **晨昏线变红**：地表上、太阳天顶角 89° 时的透射率满足 R > G > B，且 B/R < 0.2。
5. **确定性**：同一 seed 两次快进到同一时刻，回读的一小块像素完全相同。
