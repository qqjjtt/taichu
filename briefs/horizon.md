## 这一幕在算什么

一个不自转的（史瓦西）黑洞和它的吸积盘。**每个像素向后追一条光线，在弯曲时空里逐步积分它的零测地线**，
直到它落进视界、穿过吸积盘，或逃向星空。没有贴图，没有后期合成的"光环"：盘的背面被弯到上方和下方、中间那圈细细的光子环、朝你转来的一侧更亮更蓝——全部是积分的结果。

单位：`rₛ = 1`（史瓦西半径）。光子球 r = 1.5，最内稳定圆轨道 r = 3，临界碰撞参数 b_c = 3√3/2 ≈ 2.598。

## 光线积分

史瓦西时空中光子的轨道方程（u = 1/r）：`d²u/dφ² + u = (3/2)·rₛ·u²`。
它等价于在一个辅助的平直三维空间里做有心力运动，角动量 `h = |x × v|` 守恒：

```
d²x/dλ² = −(3/2)·rₛ·h²·x / |x|⁵
```

λ 就是仿射参数（因为 r²·dφ/dλ = 常数）。用它逐步推进 (x, v) 即可得到精确的轨道形状。

- 积分器：速度 Verlet 或 RK4；步长自适应（与 r 成正比，靠近光子球时更小）。先做对，再做快。
- **相机是 r_cam 处的静止观测者**。它的局域正交标架与坐标方向不同：把局域光线方向的径向分量乘以 `√(1 − rₛ/r_cam)` 再归一，才是坐标空间里的初始方向。做了这一步，阴影的视角半径才会符合辛格公式（见自检 3）。
- 终止：`r < rₛ`（稍留余量）→ 被俘获，黑；`r` 足够大且向外 → 逃逸，用出射方向 `v` 采样 `sky(dir, pixAngle)`。
- 穿过盘面（y 变号）时线性插值出交点；若交点半径在盘的范围内，累加盘的发光并按不透明度衰减后**继续积分**——高阶像（光子环）来自第二、第三次穿越。至少支持 4 次穿越。
- 远场优化（可选）：碰撞参数很大的光线偏折极小，可用 `α ≈ 2rₛ/b + (15π/16)·rₛ²/b²` 解析处理，但要与数值结果平滑衔接，星空里不能出现接缝。

## 吸积盘

几何上薄，位于 y = 0 平面，内缘 r_in = 3（最内稳定圆轨道），外缘 r_out ≈ 14，两端柔和过渡。

- 发射：`F(r) ∝ r⁻³·(1 − √(r_in/r))`，`T_emit(r) = T_peak·(F/F_max)^(1/4)`，峰值在 r ≈ 4.08。取 T_peak ≈ 9000–12000 K（把真实的紫外 / X 射线色温整体平移到可见光，保留相对关系——解剖面板里要如实说明）。
- 轨道运动：`Ω = √(rₛ / (2r³))`（史瓦西坐标下精确的开普勒角速度）；静止观测者测得的轨道速度 `β = √(rₛ / (2(r − rₛ)))`。
- 红移因子：`g = √(1 − rₛ/r)·√(1 − β²) / (1 − β·cos ψ)`。ψ 是**光子实际传播方向**（即被追踪方向的反向）与盘物质速度方向的夹角，在交点处静止观测者的局域标架里量：把方向的径向分量除以 `√(1 − rₛ/r)` 再归一。正面看（cos ψ = 0）时 `g = √(1 − 3rₛ/(2r))`。
- 观测量：`T_obs = g·T_emit`，颜色 `blackbody(T_obs)`，亮度 `∝ g⁴·F(r)`。迎面一侧会比远离一侧亮一个数量级以上——这是对的，用曝光与泛光去容纳它，不要人为压平。
- 纹理：盘不是光滑的。在随盘共转的坐标 `(r, φ − Ω(r)·t)` 里叠多层噪声，沿方位角拉长成丝缕；较差自转会把图样无限缠紧，所以用两层相位错开、交替重置并交叉淡化的做法。
- 光子环附近星空会无限缠绕、产生闪烁的碎屑：对绕行超过一圈的光线压低星空贡献，或做 2 个子样本的抗锯齿。

## 时间线（地标见契约 §7）

相机用 (距离 r, 倾角 i（与自转轴的夹角）, 方位角) 描述，全程缓动。

| 时间 | 要求 |
|---|---|
| 0–12 | r 从 60 到约 34，倾角约 77°。星空中一个极小的暗斑；随着靠近，背景星光在它周围被拉成弧——先让观众看见"空间本身弯了" |
| 12–40 | r 降到 8，倾角到 86°（几乎贴着盘面）。盘的上下两重像展开，迎面一侧炽亮 |
| 40 | `ctx.cue('closest')` |
| 40–62 | 方位角扫过约 180°，r ≈ 8–9。亮侧从画面一边移到另一边；光子环清晰 |
| 62–78 | 倾角升到约 40°（俯视整个盘，像一张唱片），r 退到 16 再到 24 |
| 78 之后 | 在高纬缓慢环绕 |

用户可拖动改变方位与倾角、滚轮改变距离（r ≥ 4）。

## 解剖面板

- lead：「每个像素向后追一条光线，在史瓦西时空里一步一步积分它的测地线，直到它落进视界、撞上吸积盘，或逃向星空。」
- equations：
  - 史瓦西度规：`ds² = −(1 − rₛ/r)·c²dt² + dr²/(1 − rₛ/r) + r²dΩ²`
  - 光子轨道：`d²u/dφ² + u = (3/2)·rₛ·u²，  u = 1/r`
  - 红移与多普勒：`g = √(1 − rₛ/r)·√(1 − β²) / (1 − β·cos ψ)`
  - 观测亮度：`I_obs = g⁴·I_emit，  T_obs = g·T_emit`
  - 阴影：`b_c = (3√3/2)·rₛ ≈ 2.598 rₛ`
- notes：
  - 「没有贴图，也没有后期合成的光环。上方和下方的弧，是同一个盘的背面被弯过来的像。」
  - 「真实吸积盘的温度在十万到千万开，主要辐射紫外线和 X 射线。这里把色温整体平移到可见光，保留相对关系。」
  - 「这是不自转的史瓦西黑洞。自转的克尔黑洞，阴影会略微不对称。」
- live：相机距离（rₛ）；倾角；本帧渲染分辨率；每条光线的最大步数。

## 物理自检

把光线积分写成一个 GLSL 字符串片段，渲染程序与探测程序共用。探测程序在一张 `rgba32f` 的 N×1 目标上，每个纹素积分一条指定参数的光线并输出结果。

1. **临界碰撞参数**：从很远处（r = 1000）以不同的 b 入射，二分找"俘获 / 逃逸"的分界，与 2.598 相差 < 0.5%。
2. **弱场偏折**：b = 50 时的总偏折角与 `2/b + (15π/16)/b²` 相差 < 1%。（这就是 1919 年爱丁顿日食观测检验的那个效应。）
3. **静止观测者看到的阴影**：相机在 r = 10，用与正片完全相同的"像素 → 初始方向"代码扫描，阴影的角半径满足辛格公式 `sin α = (3√3/2)·(rₛ/r)·√(1 − rₛ/r)`，相差 < 1%。
4. **红移因子**：r = 3、正面出射时，着色器里的红移函数给出 `g = 0.7071 ± 0.001`。

## 画面要求

- 这一幕是全片的视觉高点。定格画面：t≈40，贴着盘面，盘的背面像拱门一样跨过黑色的圆，下方一道更细的弧，中间一圈锐利的光子环，一侧炽亮偏蓝白、另一侧暗红。
- 亮侧可以很亮（场景值几十），让泛光把它烧出光晕；暗侧仍要看得见结构。
- 阴影内部是绝对的黑。
- 盘要有流动感：细密的丝缕在转，内圈快、外圈慢。
