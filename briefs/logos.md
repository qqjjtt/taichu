## 这一幕在算什么

一百万个粒子，每个都是一个阻尼弹簧振子，被拉向某个目标点，同时被一个无散度的噪声流场推动。
目标点来自文字：把一句话画进一张离屏画布，按笔画的像素采样，分给每个粒子一个落点。
这是全片的收束：从光开始，到语言结束。最后一句「你好。」之后，观众可以自己写字，粒子替他写出来。

```
a = −k·(x − x_target) − c·v + s·curl(x, t)
```

## 实现

- **粒子**：`quality` 2 → 1024²，1 → 512²，0 → 256²。位置 / 速度在 `rgba32f` ping-pong 目标里（MRT），固定子步。
- **文字光栅化**：用 2D canvas 的 `fillText`（允许，系统字体不算外部资源）。字体栈：`"Songti SC", "STSong", "Noto Serif CJK SC", "Source Han Serif SC", "SimSun", serif`——宋体的笔画有粗细，粒子写出来更像书法。在一块约 2048×1024 的画布上排版：单字时字号很大；整句时自动换行（每行至多约 10 个字）并整体缩放到视野的 70% 宽内。
- **采样目标**：读回 alpha，按覆盖度加权采样像素位置（加亚像素抖动），用确定性洗牌分给粒子；粒子多于采样点时允许重复采样点（加微小抖动）。目标纹理 `rgba32f`，与状态纹理同尺寸，按粒子索引存目标位置。每次换文字重建一次（CPU 上做，几十毫秒内完成）。
- **书写感**：换字时，粒子不同时出发：每个粒子的出发延迟由它目标点的 x 坐标（从左到右）加少量随机决定，于是字像被一笔一笔"写"出来，而不是同时浮现。散开时反过来，先松动、再被流场带走。
- **三维**：文字在 z = 0 平面上；另有约 10% 的粒子不参与写字，散布在前后不同深度，做成柔和的景深光斑（离焦越远越大越暗，能量守恒）。相机很慢地在小角度内漂移，让文字有体积感。
- **颜色**（呼应前五幕）：「光」暖白（`blackbody(6500)` 偏暖）；「星」蓝白（`blackbody(12000)`）；「海」带一点散射蓝；「生」带一点生物荧光的青绿；「言」及之后的整句与「你好。」用温暖的烛光色（`blackbody(3200)` 到 `blackbody(4500)` 之间）。粒子亮度服从幂律（少数亮，多数暗），文字边缘自然柔化。
- **呼吸**：文字成形后，弹簧刚度与噪声强度做很慢的起伏，字像在呼吸，但始终清晰可读。
- **观众输入**：`input: { placeholder: '写下一句话，按回车', maxLength: 24, at: 64 }`；`onInput(ctx, state, text)`：去掉首尾空白与控制字符；空串忽略；否则粒子散开并写出这句话。不支持的字符（emoji 等）不得报错——画不出来的就跳过。
- **文案**：`captions` 用契约 §7 的两条。

## 时间线（地标见契约 §7）

| 时间 | 要求 |
|---|---|
| 0–8 | 百万粒子像萤火 / 神经元一样在流场里漂浮，缓慢、有深度 |
| 8 / 14 / 20 / 26 / 32 | 依次写出单字：光、星、海、生、言（每个字出现时 `ctx.cue('glyph', {char})`），每个字停留约 4 秒后化开，流向下一个字 |
| 40 | 写出「宇宙花了一百三十八亿年」，`ctx.cue('line')` |
| 48 | 写出「才学会说话」，`ctx.cue('line')` |
| 54–56 | 粒子散开 |
| 56 | 写出「你好。」，`ctx.cue('hello')` |
| 64 | `ctx.cue('invite')`（界面在此时出现输入框） |
| 64 之后 | 没有输入时，「你好。」缓慢呼吸；有输入就写出观众的话，写完后保持 |

## 解剖面板

- lead：「一百万个粒子，每一个都被一根看不见的弹簧拉向一个落点。落点来自字的笔画；路上推着它们的，是一个没有源也没有汇的流场。」
- equations：
  - 阻尼弹簧：`a = −k·(x − x_target) − c·v`
  - 流场：`v_flow = ∇ × ψ`，所以 `∇·v_flow = 0`
  - 积分：`v ← v + a·Δt，  x ← x + v·Δt`
- notes：
  - 「每个粒子出发的早晚由它落点的横坐标决定，所以字是从左往右"写"出来的。」
  - 「你输入的文字被画进一张看不见的画布，再按笔画采样成一百万个落点。」
  - 「画面上没有一个字是贴图。」
- live：粒子数；当前文字；平均到位误差（像素）；流场强度。

## 物理自检（用正片的同一个积分着色器与同一个采样函数）

1. **落点都在笔画里**：对「言」采样，≥ 99.5% 的目标点落在光栅 alpha > 0.5 的像素上。
2. **会收敛**：关掉流场，从散开状态积分 3 秒，95% 的粒子到目标的距离 < 屏幕高度的 0.3%。
3. **不怕怪输入**：`onInput` 依次喂入空串、纯空格、一串 emoji、48 个字的长句，都不抛错，状态合法（无 NaN，在一张 16×16 小状态上验证）。
4. **流场无散**：数值散度 / 梯度幅值 < 0.02。
5. **确定性**：同一 seed 两次推进的校验和完全相同。

## 画面要求

- 定格画面：「你好。」——温暖的烛光色，笔画由无数细小的光点组成，边缘有少量粒子像呼出的气一样飘散，背景是深邃的黑与几颗离焦的光斑。
- 字必须清晰可读：这是一部中文片子的最后一句话。在 390×844 的手机上也要读得清。
- 克制。不要彩虹，不要爆炸特效。
