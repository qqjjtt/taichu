## 这一幕在算什么

**格雷–斯科特反应扩散**：两种化学物质 U、V 在水里扩散，V 吃 U 自我复制，同时自行衰减。
没有任何"生物学"代码，斑点却会分裂、条纹会生长、迷宫会铺开。这是图灵 1952 年《形态发生的化学基础》那个想法的一个具体模型。

```
∂u/∂t = D_u·∇²u − u·v² + F·(1 − u)
∂v/∂t = D_v·∇²v + u·v² − (F + k)·v
```

用离散形式（时间步 Δt = 1，D_u = 1.0，D_v = 0.5，9 点拉普拉斯：中心 −1，四邻 0.2，四角 0.05）。

## 实现

- **网格**：`quality` 2 → 1024²，1 → 512²，0 → 256²。周期边界。状态用 `rg32f`（或 `rgba32f`）ping-pong——半精度会让斑点"冻住"，不要用。
- **固定子步**：每次 `update` 按 `ctx.dt` 推进固定数量的子步（例如每 1/60 秒 24 步），保证快进与实时完全一致。调子步数，使斑点在 t≈40 时铺满初始视野。
- **参数场**：`(F, k)` 是空间的函数，存在一张小纹理或在着色器里由噪声算出。
  - 0–40：全场都是"有丝分裂"区（F = 0.0367，k = 0.0649）——单个斑点会长大、分裂成两个，一再重复。
  - 40 起 `ctx.cue('diverge')`：参数在约 8 秒里平滑漂移成一张由低频噪声划分的"地图"，几个区域各自落在不同的斑图区间：珊瑚 / 指纹（F≈0.0545，k≈0.062）、迷宫（F≈0.029，k≈0.057）、孤立斑点（F≈0.030，k≈0.062）、蠕虫（F≈0.078，k≈0.061）。区域边界要柔和，交界处会长出有趣的过渡形态。
  - 62–78：在 F 上叠一个很慢、很小的正弦调制（周期约 6 秒），整片斑图像组织一样"呼吸"。
- **播种**：8 秒时 `ctx.cue('spark')`，在视野中心放一个小方块的 V（加一点由 seed 决定的不对称，免得长成完美的十字对称）。之前全场是 u=1、v=0 的均匀态（它是不动点，所以 0–8 秒画面里什么也不会长）。
- **交互**：拖动 / 点击在指针处注入 V（"播种"），这是全片最好玩的一幕，要灵敏、要有手感。滚轮缩放视野。`controls: ['拖动 播种', '滚轮 远近']`。
- **渲染**（决定成败）：不要画成平面伪彩色图。把 V 当作高度场：
  - 由 V 的梯度求法线，用一个柔和的顶光加一点边缘光照亮，像在显微镜下看一层半透明的活组织；
  - 颜色克制：深海的暗青作底；斑图本身有生物荧光（偏青绿，约 480–500 nm 的颜色）与较厚处的暖色透射；高光是湿润的；
  - 可以把平面稍微倾斜成透视（相机视角从正上方偏 20–35°），配合景深，尺度感立刻就有了；
  - 0–8 秒：几乎全黑的原始海水，下方有一两处极暗的热液辉光，水中悬浮着缓慢漂移的微粒（几千个点精灵，提供深度感）。
- **视野**：开始时视野只覆盖网格中心的一小块（种子处），随斑点扩张逐渐拉远；62–78 拉到能看见整片网格，并缓慢倾斜。纹理采样用线性过滤，近看不能出现像素格。

## 时间线（地标见契约 §7）

| 时间 | 要求 |
|---|---|
| 0–8 | 黑暗的海水，微弱的热液光与漂浮微粒 |
| 8 | `ctx.cue('spark')`：一个发光的小斑点 |
| 8–40 | 一分二、二分四……斑点铺满视野。分裂的瞬间要看得清 |
| 40 | `ctx.cue('diverge')` |
| 40–62 | 条纹、迷宫、珊瑚、斑点分区共存 |

## 解剖面板

- lead：「两种化学物质，一个扩散，一个反应。没有一行代码在描述生命，斑点却会分裂、条纹会生长。」
- equations：
  - `∂u/∂t = D_u·∇²u − u·v² + F·(1 − u)`
  - `∂v/∂t = D_v·∇²v + u·v² − (F + k)·v`
  - 9 点拉普拉斯：`∇²u ≈ Σ wᵢ·uᵢ − u，  四邻 0.2，四角 0.05`
- notes：
  - 「F 是养料流入的速度，k 是 V 衰减的速度。只改这两个数，就能得到斑点、条纹或迷宫。」
  - 「图灵在 1952 年提出：两种以不同速度扩散的物质，就能自发长出斑纹。斑马和豹的花纹，很可能就是这样来的。」
  - 「你可以拖动画面播种。每一次运行都会长成不同的样子。」
- live：网格尺寸；每秒反应步数；当前视野中心的 (F, k)；V 的总量（活物质的多少）。

## 物理自检（用正片的同一个反应扩散着色器，在 128² 的小目标上做，不碰正在显示的状态）

1. **拉普拉斯精确**：对二次函数 `u = x² + y²`（离开边界的内部纹素），离散拉普拉斯 = 0.2·4 + 0.05·8 − … 按你的归一化应得到的常数，误差 < 1e-4。（先在纸上算对期望值，写进注释。）
2. **不动点**：u=1、v=0 的均匀态推进 200 步，最大偏差 < 1e-6。
3. **纯扩散守恒**：F = k = 0 且 v = 0 时，u 的总量推进 200 步后相对变化 < 1e-5。
4. **会复制**：有丝分裂参数下放一个斑点，推进足够步数后回读，用 CPU 连通域计数，斑点数 ≥ 2。
5. **确定性**：同一 seed 两次推进的校验和完全相同。

## 画面要求

- 定格画面：t≈55，倾斜的视角下，几种斑图在同一片"组织"上交界，湿润的高光，生物荧光，背景暗得像深海。
- 不要彩虹伪彩色，不要霓虹。颜色像真实的海洋生物发光。
