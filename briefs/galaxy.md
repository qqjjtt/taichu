## 这一幕在算什么

两个盘星系的相遇与并合，用**受限 N 体**方法——图姆尔兄弟 1972 年解释潮汐桥与潮汐尾时用的正是它：
两个星系核是有质量的（彼此之间真实的二体引力），一百万颗恒星是无质量的试验粒子，各自在两个核的合引力场里走自己的轨道。

```
恒星：  a(x) = − Σᵢ G·Mᵢ·(x − xᵢ) / (|x − xᵢ|² + εᵢ²)^(3/2)      （普卢默势）
积分：  v ← v + a·Δt，  x ← x + v·Δt                              （辛欧拉，固定步长）
```

## 实现

- **星系核**（CPU，JS）：两个质点 M₁ = 1、M₂ ≈ 0.4–0.6，各带普卢默软化。用蛙跳法在 CPU 上积分它们的相对轨道，再加一项模拟**动力摩擦**的阻力（只在两核靠近、晕互相重叠时显著），使它们在第二次回落时并合。每个子步把两核的位置作为 uniform 传给 GPU。
  核的轨道必须与 GPU 子步严格同步、完全确定（跳转时从头重算）。
- **恒星**（GPU）：位置与速度存在两张 `rgba32f` 的 ping-pong 目标里（MRT）。`quality` 2 → 1024²，1 → 512²，0 → 256²。每帧若干固定子步。
  位置的 w 分量、速度的 w 分量可用来存恒星的属性（所属星系、初始半径与相位、星族 / 色温、亮度等级）。
- **初始条件**：每个星系一个指数盘（面密度 ∝ e^(−r/R_d)，截到约 5 R_d）加一个小核球。盘星的初速度取所在星系势场的圆轨道速度 `v_c² = G·M·r² / (r² + ε²)^(3/2)`，加百分之几的速度弥散和薄薄的垂直厚度。约 65% 的粒子属于主星系。
  两个盘的自转轴不同：主星系相对轨道面顺行（顺行相遇共振最强，潮汐尾最长）；伴星系倾斜约 60°。
- **时间标定**：调轨道参数与"模拟时间 / 屏幕秒"的比例，使第一次近心点落在 t=30、并合落在 t=58（±1 s）。这是与配乐、字幕的约定。
- **外观**（决定这一幕成败）：
  - 恒星的光度服从幂律：绝大多数极暗极小，少数很亮。别画成一百万个一样大的点。
  - 星族与颜色只来自 `blackbody`：核球年老偏橙黄（3500–5000 K），盘偏黄白（5000–6500 K），旋臂上的年轻星团蓝白（10000–20000 K）。
  - 开场的旋臂：试验粒子没有自引力，长不出密度波。在初始条件里按对数螺线给亮度与星族"刻"上旋臂图样（密度可以均匀），它会随较差自转自然缠卷。
  - "尘埃带"：加色混合没法变暗。把每颗星的亮度乘上一个定义在**初始盘坐标**上的噪声遮罩，遮罩随粒子一起运动、被较差自转剪切成丝缕——这就是旋臂间的暗带与絮状结构。
  - 相遇引发的**星暴**：恒星受到来自"另一个星系"的潮汐加速度超过阈值时点亮一个"星暴"标记，瞬间变成明亮的蓝白，再用约 8 秒褪回原色。于是桥与尾会在掠过时闪出一串蓝色的星团——这在物理上是对的（潮汐压缩气体触发恒星形成）。
  - 两个核各有一团柔和的核球辉光；并合瞬间（t=58）核心明显增亮一次。
  - 背景用 `sky`，压暗到不抢戏；镜头拉远的结尾可以稍微提亮它，让星系真正成为"众星之一"。
- 点精灵按 `ctx.px` 缩放；镜头贴近盘面时限幅，避免重绘爆炸。

## 时间线（地标见契约 §7）

| 时间 | 要求 |
|---|---|
| 0–14 | 一个安静的盘星系占据画面，略带倾角，缓慢自转。接上一幕结尾的那团星光 |
| 14–30 | 镜头拉开，伴星系从一侧接近 |
| 30 | `ctx.cue('pass1')`。第一次近心点 |
| 30–48 | 潮汐桥连起两个星系，两条长尾向外甩出。这是全幕的定格画面，镜头要给它时间和角度 |
| 48–58 | 两核回落 |
| 58 | `ctx.cue('merge')`。并合，核心闪亮 |
| 60–86 | 余晖：壳层、星流缓缓回落、相混；镜头持续拉远，最后星系只是星空里一小团光 |
| 86 之后 | 遗迹缓慢自转，镜头在远处缓慢环绕，保持稳定 |

镜头：`OrbitCamera`，用户可拖动与缩放。

## 解剖面板

- lead：「一百万颗恒星，各自在两个星系核的引力场里走自己的轨道。恒星之间互不作用——1972 年，图姆尔兄弟就是这样第一次算出了潮汐尾。」
- equations：
  - 恒星的加速度：`a = −Σᵢ G·Mᵢ·(x − xᵢ) / (|x − xᵢ|² + εᵢ²)^(3/2)`
  - 积分：`v ← v + a·Δt，  x ← x + v·Δt`
  - 圆轨道速度：`v_c² = G·M·r² / (r² + ε²)^(3/2)`
- notes：
  - 「两个星系核之间是真正的二体引力，外加一项模拟动力摩擦的阻力，所以它们最终并合。」
  - 「蓝色的闪光是星暴：潮汐力压缩气体，触发成批的恒星诞生。这里用潮汐加速度的大小来近似。」
  - 「没有一颗恒星相撞。恒星之间的距离，是恒星直径的几千万倍。」
- live：恒星数；两核间距（千光年，取 R_d ≈ 1 万光年换算）；相对速度（km/s，取典型圆轨道速度 ≈ 220 km/s 换算）；经过的时间（亿年，整幕约对应 15 亿年）。

## 物理自检（用真正在跑的那个积分着色器，在一张 8×1 的小状态目标上做）

1. **圆轨道保持圆**：伴星系质量置 0，试验粒子按 v_c 放在若干半径上，积分 4000 步，半径偏差 < 1%。
2. **周期正确**：同上，粒子转过的角度与 `v_c·t / r` 相差 < 1%。
3. **二体能量守恒**：CPU 上的核轨道积分器，关掉摩擦项跑 5000 步，`|ΔE/E| < 1e-3`。
4. **确定性**：同一 seed 把模拟推进 600 步两次，状态校验和完全相同。

## 画面要求

- 参照物是真实的星系照片（哈勃拍的触须星系、涡状星系），不是游戏里的"星云特效"。
- 颗粒感很重要：能看出"这是无数颗星"，而不是一团发光的雾。
- 潮汐尾要细、长、有疏密变化。

## 性能

积分几乎不花钱；成本在一百万个加色点的填充。1280×720 下 `gpuAvgMs ≤ 8`。
