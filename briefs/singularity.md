## 这一幕在算什么

宇宙大尺度结构的形成，用**泽尔多维奇近似**（一阶拉格朗日微扰论，1970）：
每个质点的位置 = 初始位置 + 增长因子 × 位移场，位移场是一个高斯随机势的负梯度。

```
x(q, t) = q + D(t)·ψ(q)，   ψ(q) = −∇Φ(q)
```

它不需要保存任何模拟状态：位置是 (q, t) 的纯函数，在**顶点着色器**里由 `gl_VertexID` 当场算出。
这让我们能画两百万个质点而几乎不花模拟成本，并且天然确定、可任意跳转。

## 实现

- 质点数：`quality` 2 → 128³ = 2 097 152；1 → 80³；0 → 50³。`q` 取 [-1,1]³ 的规则格点再加整格范围的均匀抖动（D=0 时必须看不出晶格）。
- 势场 Φ：4–5 个倍频的梯度噪声之和，用 `noised` 片段的解析梯度直接得到 ψ。大尺度的功率要多一些（纤维要长、空洞要大），小尺度只添细节。
- 密度代理：对带限噪声，−∇²(第 k 个倍频) ≈ k²·(该倍频的值)，所以把同一批噪声值按 `振幅×频率²` 重新加权求和，就得到线性密度涨落 δ ∝ −∇·ψ，不必再做有限差分。用它给质点上色、决定哪里点亮第一批恒星。
- 壳层穿越：D 过大时质点会穿过结点继续飞走，纤维变糊。让有效位移在第一次穿越附近饱和（比如 `ψ·D / (1 + c·D·max(δ,0))` 这一类的软钳制），保住纤维的锐度。
- 尺度因子：早期用物理坐标 `x_phys = a(t)·x`（爆炸的外涌感来自这里），到 t≈30 平滑过渡为共动坐标（之后我们"跟着宇宙一起膨胀"看结构生长）。辐射时期 a ∝ t^(1/2)，物质时期 a ∝ t^(2/3)，D ∝ a。
- 渲染：加色点精灵，线性 HDR。每个质点的亮度恒定，密度自然变成亮度。点很小（1–3 像素），按 `ctx.px` 缩放；离镜头很近的点要限幅并淡出，否则会出现巨大的光斑和可怕的重绘。做一点景深：离焦平面远的点变大变暗（能量守恒），画面立刻有了镜头感。
- 不要每帧上传顶点数据。无属性 VAO + `gl_VertexID`。

## 时间线（章内秒；地标见契约 §7，不得移动）

| 时间 | 要求 |
|---|---|
| 0–6 | 纯黑。画面正中一个极小、极亮的光点，缓慢呼吸（用 `ctx.wall`，因为片头待机时 time 恒为 0）。这是整部片子的第一个画面，也是开始界面的背景：要安静、精确，像真空里的一颗针尖 |
| 6–13.5 | 光点失稳。涨落：细碎的闪烁向中心收紧，亮度与颤动逐渐加剧。不要画成"能量球" |
| 13.5 | `ctx.cue('bang')`。白闪：全屏加色，0.35 s 升起、约 2.5 s 衰减（`reducedMotion` 时幅度减半） |
| 13.5–30 | 质点自中心外涌，掠过并包住镜头。整个画面是发光的等离子体：颜色用 `blackbody(T)`，T 随 1/a 从约 30000 K 降到 **3000 K**——那正是光与物质脱耦时的真实温度，画面在 t=30 应当是一片炽热的橙色。除质点外加一层全屏的均匀辉光来表现"不透明" |
| 30 | `ctx.cue('dark')`。之后 10 秒，辉光散去，质点红移变暗，画面沉入近乎全黑的暗红余烬 |
| 40–70 | D 从 0 增长。均匀的尘埃里先出现隐约的浓淡，然后是薄片、纤维、结点、空洞——宇宙网。空洞要真的空、真的黑。纤维偏暖，结点更亮更白 |
| 52 | `ctx.cue('firstlight')`。密度最高的结点里，第一批恒星逐个点亮（明亮的蓝白 HDR 点，带泛光，轻微闪烁），数量逐渐增多 |
| 70–84 | 镜头缓慢推向最亮的一个结点（事先在 CPU 上用同一套噪声找出它的位置），最后一帧是一团密集的星光占据画面中心，准备切到第二幕的星系 |
| 84 之后 | 停在结点近旁缓慢环绕，恒星继续闪烁，D 不再增长 |

镜头：`OrbitCamera`，导演机位随时间走；用户可拖动环视、滚轮远近。

## 解剖面板

- lead：「两百万个质点，没有一个被保存。每一帧，每个质点的位置都由同一条公式当场算出：初始位置，加上一个随时间增长的位移。」
- equations：
  - 泽尔多维奇近似：`x(q, t) = q − D(t)·∇Φ(q)`
  - 密度：`ρ/ρ̄ = 1 / det(I − D·∂²Φ/∂qᵢ∂qⱼ)`
  - 辐射时期：`a ∝ t^(1/2)，T ∝ 1/a`
  - 物质时期：`a ∝ t^(2/3)，D ∝ a`
- notes：
  - 「Φ 是一个高斯随机场：早期宇宙里十万分之一的密度起伏。」
  - 「位移是势的梯度，所以没有旋度——物质只会沿着"下坡"聚拢。自检会验证这一点。」
  - 「画面变成橙色的那一刻约 3000 K：光与物质脱耦时的真实温度。那片光今天还在，已经冷到 2.725 K，叫宇宙微波背景。」
- live：质点数；红移 z；背景温度 `T = 2.725·(1+z)` K；增长因子 D。z 随时间单调下降，t=30 时 z=1100（T≈3000 K），片尾 z≈15。

## 物理自检（`selfTest`，检验真正在跑的那份着色器函数）

把"由 q 与 D 算位置"的 GLSL 写成一个字符串片段，渲染程序与一个小小的探测程序共用它；探测程序把结果写进 `rgba32f` 小目标，再 `readFloat` 回来。

1. **D = 0 时位移为零**：`max|x − q| < 1e-6`。
2. **位移场无旋**：在 64 个随机点上用中心差分求 ∇×ψ，`|∇×ψ| / |∇ψ| < 0.03`。
3. **密度代理是真的密度**：在 256 个随机点上，上色用的密度代理与有限差分得到的 −∇·ψ 的相关系数 > 0.9。
4. **3000 K**：live 面板用的 z(t) 在 t=30 给出 `2.725·(1+z)` 落在 3000 K ± 2%。

## 画面要求

- 这一幕的定格画面有两个：白闪后炽热的橙色等离子体；以及宇宙网完全成形、第一批恒星点亮的那一刻。后者要让人想起真实的宇宙学模拟图，而不是"粒子特效"。
- 黑是真黑。40 秒附近画面可以暗到几乎什么都没有——那是对的，别怕。
- 不要彩虹色，不要紫粉。颜色只来自温度。

## 性能

1280×720 下 `gpuAvgMs ≤ 10`。主要成本是顶点着色器里的噪声与近处大点的重绘；需要时设 `renderScale`。
